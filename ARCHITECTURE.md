# Архитектура AVF Repair v2

## До доработки
Статические HTML, CSS и JavaScript без зависимостей: главная, портфолио, контакты. Услуги открывались в диалоге, проекты не имели страниц, форма только проверяла заполнение. Источник GitHub Pages — docs/ ветки main. Исходный коммит v2: 73b2835.

## После доработки
Стек сохранён. Node.js используется только для статической генерации, сервер приложению не требуется.
- src/data.mjs — редактируемые данные услуг, проектов, FAQ, этапов и показателей; граница для будущей CMS.
- src/config.mjs — основной URL, контакты, аналитика, режим формы.
- scripts/build.mjs — общие HTML-компоненты, статические страницы, SEO и sitemap.
- src/style.css и src/app.js — оформление и браузерные компоненты без библиотек.
- docs/ — готовые файлы GitHub Pages; редактируются через исходники и сборку.

Фотографии, реквизиты, гарантии и показатели не выдумываются. Заглушки явно подписаны. Иллюстрации SVG — схемы, не фотографии проектов. Политика — незавершённый документ для согласования. События аналитики не включают поля формы, имена файлов, фотографии и контактные данные. Идентификаторы аналитики пусты; скрипты провайдеров не загружаются до их настройки.

Форма по умолчанию работает локально. После подключения endpoint реальный form_success разрешён только при ответе {"success":true}. Контракт приёма описан в README. Публикация и merge требуют отдельного подтверждения.
